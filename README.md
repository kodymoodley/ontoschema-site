# OntoSchema — built site

This repository holds the **compiled output** of OntoSchema. Nothing here is written by hand: every
file is generated by a build in the private source repository and force-pushed over whatever was
here before. An edit made in this repository will be undone, without warning, by the next deploy.

**The live app is at https://kodymoodley.github.io/ontoschema-site/**

The source, its history, its tests and its licence are in the private `ontoschema` repository. This
repository is a delivery mechanism rather than something to read or fork.
